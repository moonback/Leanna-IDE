# Présentation des Documents Markdown

> S'applique à **tout fichier `.md` produit**. Objectif : lisible et scannable.

## Structure
- **H1 unique** + phrase d'accroche ; **sommaire** si > 3 sections.
- Hiérarchie `##` puis `###`, sans saut de niveau.

## Lisibilité
- Paragraphes courts, listes privilégiées, une idée par puce.
- **Gras** pour les termes-clés, `code inline` pour les identifiants techniques.
- Une ligne vide entre chaque bloc.

## Éléments visuels
- **Tableaux** pour comparer ; blocs de code toujours balisés (` ```ts `, ` ```bash `).
- `>` pour les notes, `- [ ]` pour les plans d'action.
- `✅` `⚠️` `❌` avec parcimonie ; `---` pour séparer les grandes parties.

## À proscrire
Murs de texte, emojis en excès, H1 multiples, blocs de code sans langage, URL brutes.
