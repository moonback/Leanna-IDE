# 🗺️ Roadmap — Jarvis-OS Document Intelligence

> Feuille de route pour transformer Jarvis-OS en plateforme de gestion documentaire pilotée par l'IA.

---

## 📌 Vision

Faire de Jarvis-OS l'assistant documentaire ultime : un outil qui comprend, génère, organise et améliore tous les documents d'un projet — des MVPs aux rapports de conception — avec un minimum d'effort humain.

---

## Phase 1 — Fondations Documentaires (v0.5.0) ✅

> Objectif : Remplacer le paradigme "IDE code" par un paradigme "espace documentaire".

| Tâche | Statut | Description |
| :--- | :---: | :--- |
| Refonte des prompts système | ✅ | Orientation document dans base.md, safety.md, autonomy.md, efficiency.md |
| Mise à jour du README | ✅ | Nouvelle identité : assistant IA documentaire |
| Suppression des références code | ✅ | Plus de verify_file, lint, compilation dans le core |
| Définition des types de documents | ✅ | MVP, rapport, cahier des charges, spec, plan, roadmap |

---

## Phase 2 — Moteur de Templates (v0.6.0)

> Objectif : Bibliothèque de modèles de documents pré-structurés.

| Tâche | Statut | Description |
| :--- | :---: | :--- |
| Template MVP | 🔲 | Structure standard : vision, problème, solution, métriques, timeline |
| Template Rapport de Conception | 🔲 | Architecture, choix techniques, contraintes, alternatives |
| Template Cahier des Charges | 🔲 | Contexte, exigences fonctionnelles/non-fonctionnelles, glossaire |
| Template Spécification Technique | 🔲 | API, schémas, protocoles, exemples |
| Template Plan de Projet | 🔲 | Objectifs, jalons, livrables, risques, planning |
| Template Note de Recherche | 🔲 | Problématique, état de l'art, méthodologie, résultats |
| Système de variables | 🔲 | Placeholders dynamiques (nom projet, date, auteur) |
| UI de sélection de template | 🔲 | Panneau avec preview et personnalisation |

---

## Phase 3 — IA Rédactionnelle (v0.7.0)

> Objectif : Capacités de rédaction avancées pilotées par Gemini.

| Tâche | Statut | Description |
| :--- | :---: | :--- |
| Génération de document complet | 🔲 | Créer un document structuré à partir d'un brief oral ou textuel |
| Rédaction section par section | 🔲 | Remplissage intelligent de chaque section d'un template |
| Reformulation et simplification | 🔲 | Adapter le niveau de langage au public cible |
| Résumé automatique | 🔲 | Condensation d'un document long en executive summary |
| Expansion de bullet points | 🔲 | Transformer des notes brèves en paragraphes rédigés |
| Détection de ton | 🔲 | Identifier et maintenir un ton cohérent (formel, technique, vulgarisé) |
| Multi-langue | 🔲 | Rédaction et traduction FR/EN/AR avec adaptation culturelle |

## Phase 4 — Knowledge Graph Documentaire (v0.8.0)

> Objectif : Graphe de relations entre tous les documents du projet.

| Tâche | Statut | Description |
| :--- | :---: | :--- |
| Indexation par sections | 🔲 | Chaque section de chaque document est un nœud du graphe |
| Relations inter-documents | 🔲 | Liens automatiques (le cahier des charges référence le MVP) |
| Détection de contradictions | 🔲 | Alerte quand deux documents se contredisent |
| Détection de doublons | 🔲 | Signaler les contenus redondants entre documents |
| Recherche sémantique | 🔲 | Trouver un concept dans toute la base documentaire |
| Graphe visuel | 🔲 | Visualisation interactive des relations entre documents |
| Suggestions de liens | 🔲 | Proposer des connexions pertinentes entre documents |

## Phase 5 — Collaboration & Workflow (v0.9.0)

> Objectif : Chaînes de production documentaire automatisées.

| Tâche | Statut | Description |
| :--- | :---: | :--- |
