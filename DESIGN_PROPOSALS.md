# Propositions d'Amélioration du Design - Leanna

Ce document rassemble des pistes concrètes pour rendre l'interface de Leanna plus professionnelle, moderne et intuitive.

## 1. Principes Clés

*   **Clarté & Minimalisme** : Réduire le bruit visuel. Chaque élément doit avoir une fonction claire.
*   **Hiérarchie Visuelle** : Guider l'œil vers les actions principales (Ouvrir le chat, Nouveau fichier).
*   **Cohérence** : Utiliser une palette de couleurs et une typographie uniformes.

## 2. Pistes d'Amélioration Visuelle

### Palette de Couleurs
*   **Identité visuelle** : Utiliser impérativement les couleurs du logo de Maysson pour l'accentuation, les boutons d'action principaux et les éléments clés d'identité (Accents trouvés dans le CSS : `#00c2ff` et `#ff8c00`).
*   Utiliser des nuances de gris pour le fond, les bordures et le texte afin de créer de la profondeur sans surcharger.

### Accueil
*   **Boutons principaux** : Agrandir et centrer les actions "Nouveau fichier", "Rechercher", etc., pour les rendre plus proéminentes.
*   **Fichiers récents** : Clarifier la liste, peut-être avec des icônes de type de fichier plus distinctes.

### Barre Latérale (Explorateur)
*   **Espacement** : Augmenter légèrement l'espacement entre les fichiers/dossiers pour une meilleure lisibilité.
*   **Icônes** : Utiliser un set d'icônes plus moderne et cohérent pour les dossiers et types de fichiers.

## 3. Expérience Utilisateur (UX)

*   **Feedback contextuel** : Ajouter des animations subtiles lors du survol des éléments ou lors du chargement. Mettre l'accent sur la fluidité pour donner une impression de performance et de "pensée" de l'IA (ex: transitions douces entre les panneaux).
*   **Identité IA** : Mettre en avant les capacités de l'agent IA dès l'accueil, en guidant l'utilisateur vers les interactions possibles.
*   **Thèmes** : Proposer un thème clair et un thème sombre.
